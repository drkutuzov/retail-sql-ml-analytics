# Retail SQL & Machine Learning Analytics

An end-to-end data analytics project using Python, SQL,
and machine learning to analyze retail transactions
and forecast revenue.

## Project objectives

- Design a relational SQLite database.
- Clean and transform real-world retail transaction data.
- Analyze business performance using SQL.
- Integrate SQL queries with Python and Pandas.
- Develop machine learning models for revenue forecasting.
- Build reproducible data analysis workflows.

## Technologies

- Python 3.13
- SQLite
- Pandas
- Scikit-learn
- Matplotlib
- JupyterLab

## Dataset

UCI Online Retail Dataset:
https://archive.ics.uci.edu/dataset/352/online+retail
